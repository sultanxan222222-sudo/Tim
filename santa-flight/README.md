# Santa Flight — 16-bit

Полноценная браузерная аркада с адаптацией под телефон и установкой как PWA.

## Как играть
Открой опубликованную страницу игры. На ПК используй ↑/↓ или W/S либо мышь. На телефоне веди пальцем по игровому полю. Пробел — пауза.

## Установка на Android
Открой игру в Chrome, нажми меню браузера → «Установить приложение» или «Добавить на главный экран». После первой загрузки игра работает офлайн.

## Возможности
- Санта в санях и оленья упряжка.
- Подарки, очки, жизни, рекорд.
- Самолёты и бельевые верёвки как препятствия.
- Адаптивное сенсорное управление.
- PWA-манифест и офлайн-кэш.
- GitHub Actions: проверка JavaScript, ZIP-архив и публикация GitHub Pages.

Исходный проект расположен отдельно в `santa-flight/`; остальные части репозитория Tim не затрагиваются.
