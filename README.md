# TIM · PS4 Game Catalog

Проект `Tim` — карточный каталог для PS4. Текущий репозиторий содержит веб-прототип интерфейса, а не нативный пакет PS4.

## Единственный подключённый источник каталога

- PirateGames — каталог PS4: https://pirategames.ru/ps4/
- Love-Games1 — раздел игр PS4: https://love-games1.net/load/igry_dlja_konsolej/igry_dlja_playstation_4/42 (внешняя ссылка для открытия сайта; автоматический разбор страниц не реализован)

Другие ранее добавленные источники из `catalog.json` удалены по запросу.

## Текущее состояние

- Карточки, обложки, поиск, фильтры, сортировка и подробности.
- В списке источников каталога доступны PirateGames и внешний раздел PS4 на Love-Games1; последний открывается как ссылка на сайт, а не как прямой URL PKG.
- Можно подключить внешний JSON-каталог в формате проекта или формате FPKGi `DATA`.
- Прямые кнопки скачивания работают только при наличии прямого URL пакета в записи.
- Добавление сайта как источника пока не означает, что его страницы автоматически разобраны на карточки или что прямые ссылки на PKG уже получены. Автоматический сбор каталога с PirateGames ещё нужно реализовать и проверить.
- Это веб-прототип, а не устанавливаемый PS4 PKG. Нативная очередь загрузок, фоновая загрузка и установка на консоли ещё не реализованы.

## Формат каталога

```json
{
  "sources": [
    {
      "id": "authorized-source",
      "name": "Источник каталога",
      "url": "https://example.org/catalog.json",
      "type": "json"
    }
  ],
  "games": [
    {
      "id": "example-homebrew",
      "title": "Example Homebrew",
      "titleId": "ABCD12345",
      "category": "Homebrew",
      "region": "EUR",
      "version": "1.00",
      "size": 100000000,
      "coverImage": "https://example.org/cover.png",
      "downloadUrl": "https://example.org/authorized-package.pkg",
      "notes": "Пример структуры; URL условные."
    }
  ]
}
```

Используй пакеты, которые разрешено распространять или которыми владеешь.
