# PS4-FPKGi — каталог игр и homebrew

Первый этап проекта: интерфейс каталога, поиск и переходы к исходным каталогам.

## Источники каталога
- [PSPrices — бесплатные игры PS4](https://psprices.com/region-ru/collection/free?platform=PS4)
- [PlayStation Store — каталог](https://store.playstation.com/ru-ru/category/30749d2c-738f-4c36-9d6b-7ed517cca9ee/)
- [Rocket League — поиск в Store](https://store.playstation.com/ru-ru/search/rocket%20league)
- [Brawlhalla — поиск в Store](https://store.playstation.com/ru-ru/search/brawlhalla)

## Запуск прототипа
Откройте `index.html` в браузере. Никакие пакеты или установщики не загружаются автоматически.

## Важные ограничения
Страницы Store и PSPrices — источники метаданных и ссылок, а не прямые ссылки на PKG. Прямые загрузки следует подключать только для легально распространяемых homebrew, public-domain проектов или файлов, на распространение которых у пользователя есть права. Установка PKG на PS4 зависит от возможностей и ограничений самой консоли.
