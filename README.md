# PS4-FPKGi — карточный каталог для PS4

Проект повторяет основные принципы FPKGi в собственном интерфейсе с карточками игр. Веб-версия — рабочий прототип интерфейса, не готовый нативный пакет PS4.

## Уже реализовано в веб-прототипе

- Карточки игр с обложками и резервным оформлением.
- Поиск по названию, Title ID, категории и региону.
- Фильтр категорий.
- Сортировка по названию, размеру и региону.
- Окно подробностей: категория, Title ID, версия, размер, регион, дата релиза и минимальная прошивка.
- Подключение удалённого JSON-каталога по URL.
- Разбор формата FPKGi `DATA` и собственного `catalog.json`.
- Прямая ссылка на пакет показывается только если она есть в записи каталога.
- Ссылки на предоставленные пользователем страницы PSPrices и PlayStation Store.

## Подключение удалённого каталога

Откройте прототип в браузере, вставьте URL JSON-каталога в поле «Подключить JSON-каталог FPKGi» и нажмите «Загрузить каталог». Удалённый сервер должен разрешать браузерные запросы через CORS. Если сервер не разрешает CORS, загрузка из веб-интерфейса не сработает — потребуется серверный прокси или нативная реализация сетевого запроса.

Поддерживаемый формат FPKGi:

```json
{
  "DATA": {
    "https://example.org/authorized-content.pkg": {
      "region": "EUR",
      "name": "Example Homebrew",
      "version": "1.00",
      "release": "10-20-2026",
      "size": "100000000",
      "min_fw": null,
      "cover_url": "https://example.org/cover.png"
    }
  }
}
```

URL пакета должен быть прямым URL на файл и должен указывать на контент, который разрешено распространять или который принадлежит пользователю. Размер указывается в байтах.

## Источники каталога по умолчанию

- [PSPrices — бесплатные игры PS4](https://psprices.com/region-ru/collection/free?platform=PS4)
- [PlayStation Store — каталог](https://store.playstation.com/ru-ru/category/30749d2c-738f-4c36-9d6b-7ed517cca9ee/)
- [Rocket League — поиск в Store](https://store.playstation.com/ru-ru/search/rocket%20league)
- [Brawlhalla — поиск в Store](https://store.playstation.com/ru-ru/search/brawlhalla)

Эти страницы служат источниками информации о продуктах. Они не являются прямыми URL для загрузки PKG.

## Что ещё не готово

- Нативная сборка `.pkg` для запуска непосредственно на PS4.
- Нативная загрузка файлов в фоне, очередь загрузок и установка пакетов через механизмы PS4.
- Автоматическое обнаружение новых игр в PS Store/PSPrices и обновление метаданных без предоставленного JSON-источника.
- Полная проверка интерфейса на самой консоли.

Для нативной сборки требуется совместимая среда разработки PS4/homebrew и проверка её доступности. Веб-прототип нельзя устанавливать на PS4 как приложение `.pkg`.

## Запуск веб-прототипа

Откройте `index.html` в браузере или разместите файлы проекта на статическом веб-хостинге. Для локального `catalog.json` удобнее использовать HTTP-хостинг, а не открытие файла через `file://`.
