# TIM · PS4 PKG Catalog

Карточный каталог для проекта PS4 homebrew/HEN. Текущая версия — веб-прототип интерфейса, не нативный пакет PS4. В исходном каталоге заведены карточки Rocket League, Brawlhalla и Fall Guys на основе URL, предоставленных пользователем.

## Что умеет прототип

- Карточки, обложки, поиск и сортировка каталога.
- Подключение внешнего JSON-каталога по URL.
- Поддержка собственного формата `catalog.json` и формата FPKGi `DATA`.
- Чтение метаданных: название, Title ID, регион, версия, размер, дата релиза, минимальная версия системного ПО.
- Кнопка «Скачать PKG» для записей с прямым URL пакета.

## Подключение каталога

В поле «Подключить каталог PKG» вставь URL JSON-файла и нажми «Подключить». Веб-сервер источника должен разрешать запросы из браузера (CORS). Для настоящего каталога нужны прямые ссылки на файлы PKG и соответствующие метаданные; ссылки на обычные веб-страницы не заменяют URL пакетов.

Формат проекта:

```json
{
  "sources": [],
  "games": [
    {
      "id": "example-homebrew",
      "title": "Example Homebrew",
      "titleId": "ABCD12345",
      "category": "Homebrew",
      "region": "EUR",
      "version": "1.00",
      "size": 100000000,
      "release": "2026-10-20",
      "min_fw": "—",
      "coverImage": "https://example.org/cover.png",
      "downloadUrl": "https://example.org/authorized-package.pkg",
      "notes": "Пример структуры; URL условные."
    }
  ]
}
```

Поддерживается и формат FPKGi:

```json
{
  "DATA": {
    "https://example.org/authorized-package.pkg": {
      "region": "EUR",
      "name": "Example Homebrew",
      "version": "1.00",
      "release": "10-20-2026",
      "size": "100000000",
      "min_fw": null,
      "cover_url": "https://example.org/cover.png"
    }
  }
}
```

Размер может быть указан в байтах. Используй источники и пакеты, которые разрешено распространять или которыми владеешь.

## Что ещё не реализовано

- У карточек Rocket League, Brawlhalla и Fall Guys пока нет подтверждённых прямых PKG URL; предоставленные ссылки используются как источники сведений о названиях игр, а не как ссылки на файлы.
- Нативная сборка `.pkg` для запуска непосредственно на PS4.
- Нативная фоновая загрузка, очередь загрузок и установка пакетов на консоли.
- Полное тестирование на PS4.

Веб-прототип не является устанавливаемым приложением PS4. Прямые загрузки в браузере также зависят от поведения браузера и настроек сервера источника.
