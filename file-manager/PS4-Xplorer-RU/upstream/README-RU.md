# Исходники PS4-Xplorer RU

Эта папка содержит рабочие копии исходных C#-скриптов из публичного проекта [Lapy055/PS4-Xplorer](https://github.com/Lapy055/PS4-Xplorer), дополненные русскими строками интерфейса. Автор оригинала — Lapy; все исходные права и лицензия остаются за автором.

## Уже переведено в исходниках
- Основной контроллер: сообщения копирования/перемещения, ошибка пустого буфера, ошибка создания папки, подпись справки.
- Контекстное меню: создать папку, вырезать, копировать, вставить, переименовать, удалить, подтверждение удаления.
- Сохранены оригинальные методы и логика файлового менеджера; это переводная правка, а не переписывание приложения.

## Что ещё требуется
Полная локализация Unity-проекта требует проверить все C#-скрипты, сцены и префабы, затем собрать PKG тем же набором Unity/PS4 SDK, которым собирался совместимый оригинал. Эти копии скриптов сами по себе не являются устанавливаемым PKG. До сборки и проверки на консоли нельзя обещать, что пакет работает.
