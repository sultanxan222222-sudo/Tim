# Тест-план PS4-Xplorer RU

Отмечать пункт только после фактической проверки. «Не проверено» не равно «пройдено».

- [ ] Unity-проект открывается без ошибок импорта.
- [ ] Все C#-скрипты компилируются.
- [ ] Сцена запускается в целевой конфигурации.
- [ ] PKG собран; лог сохранён.
- [ ] SHA-256 PKG записан.
- [ ] PKG устанавливается на целевой PS4.
- [ ] Приложение запускается с главного экрана.
- [ ] Русские подписи не обрезаны и читаемы.
- [ ] В подсказке OPTIONS корректный перенос строки.
- [ ] Навигация вверх/вниз/подтверждение/назад работает.
- [ ] Открытие папки и возврат на уровень выше работают.
- [ ] Пустая папка отображается корректно.
- [ ] Недоступный путь не приводит к аварийному выходу.
- [ ] Создание папки работает.
- [ ] Повторное имя папки показывает предупреждение.
- [ ] Переименование работает и сохраняет расширение файла.
- [ ] Копирование файла работает.
- [ ] Перемещение файла работает.
- [ ] Вставка без предварительного копирования показывает сообщение.
- [ ] Конфликт имён не перезаписывает данные без подтверждения.
- [ ] Отмена операции оставляет исходный файл целым.
- [ ] Удаление требует подтверждения.
- [ ] USB 0 проверен с подключённым накопителем.
- [ ] USB 1 проверен, если доступен на целевой конфигурации.
- [ ] Отключение USB обрабатывается без зависания.
- [ ] Большой файл проверен на копирование и свободное место.
- [ ] FTP отдельно проверен, если поддерживается в собранной версии.
- [ ] Проверены выход из приложения и повторный запуск.

**Результат:** дата / модель PS4 / версия исходника / SHA-256 PKG / пройденные пункты / известные ошибки.
