# Условия допуска к выпуску

Релиз нельзя помечать готовым к установке, пока не выполнены все пункты:

- [ ] Получен полный Unity-проект точной целевой версии.
- [ ] Подтверждены права на изменение и распространение.
- [ ] Патч применён к чистой копии исходников; diff проверен человеком.
- [ ] Все C#-скрипты компилируются в совместимой Unity PS4-среде.
- [ ] Проверены русские шрифты и все экраны/диалоги.
- [ ] Собран PKG, сохранён лог сборки.
- [ ] Для PKG вычислен SHA-256.
- [ ] Пакет установлен на целевую консоль.
- [ ] Подтверждены запуск, навигация и основные файловые операции.
- [ ] Проверены ошибки, отмена, конфликты имён и USB.
- [ ] Пройден весь [тест-план](TEST-PLAN-RU.md).
- [ ] Известные ограничения опубликованы.

Пока пункты не закрыты, статус остаётся **«частичный исходный патч; не готов к установке»**. Успех GitHub Actions означает только прохождение указанных автоматических проверок.
