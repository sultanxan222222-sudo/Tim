# Как продолжать разработку

1. Работайте в отдельной копии исходников PS4-Xplorer.
2. Сначала выполните проверку совместимости:
   `python file-manager/PS4-Xplorer-RU/apply_russian_patch.py --dry-run`
3. Только после успешной проверки примените патч:
   `python file-manager/PS4-Xplorer-RU/apply_russian_patch.py`
4. Просмотрите diff всех изменённых C#-файлов; не принимайте изменения вслепую.
5. Запустите локальные проверки:
   `python file-manager/PS4-Xplorer-RU/tests/check_localization.py`
   `python file-manager/PS4-Xplorer-RU/tests/test_patch_script.py`
6. Не запускайте патчер второй раз на тех же исходниках: он намеренно остановится, чтобы не дублировать код.
7. Не переносите патч на другой upstream commit, если dry-run или CI завершился ошибкой; сначала изучите изменившуюся структуру исходника.
8. Любое изменение интерфейса сопровождайте тестом и обновлением словаря.
9. Не называйте исходный патч готовым приложением. Для выпуска нужны Unity-компиляция, сборка PKG и тест на реальной консоли.
