# Dreamcast Android TV

Отдельная Android TV-сборка Sega Dreamcast для приставки Rockchip RK3528 (4 ГБ RAM, 32 ГБ накопитель).

## Устройство проекта

Программа строится на закреплённой версии upstream Flycast и его настоящем Android-порту. PS4-специфичные Vulkan/GNM-модули из соседней ветки не переносятся в Android вслепую. Ветка: `android-tv-dreamcast`.

## Уже добавлено в эту ветку

- Закреплён Flycast как git submodule на commit `72b8e67141d85ca5c9259f04563b49f7f92f928b`.
- Добавлен TV-first экран запуска на русском языке с крупной навигацией под D-pad.
- Добавлен выбор игры через системный Android Storage Access Framework, в том числе с USB-накопителя, если его предоставляет системный файловый picker.
- Добавлен список до пяти недавних игр с сохранением URI-доступа, когда провайдер поддерживает постоянное разрешение.
- Добавлен переход в штатный интерфейс ядра Flycast.
- Добавлена CI-сборка APK и публикация APK как GitHub Actions artifact.

## Утверждённые требования к следующим модулям

- Android 13 и 14; русская TV-навигация и поддержка пульта/геймпада.
- Игровая библиотека и USB-носители.
- Сохранения и состояния через реальные функции Flycast.
- Автоматическое определение PAL/NTSC и игрового темпа. Нельзя искусственно ограничивать 50/60-FPS игры до 30 FPS.
- Графические профили: «Производительность», «Баланс», «Качество».
- Внутреннее разрешение до 1800p — только в пределах реальных возможностей рендерера и драйвера; это не гарантия стабильной работы на RK3528.
- Сглаживание и остальные графические настройки выводятся только при фактической поддержке backend.
- Ретро-фильтры — отдельная необязательная функция, по умолчанию выключена; одновременно активен максимум один фильтр.
- Настройки не должны быть декоративными: значение появляется в интерфейсе только после подключения к реальному параметру ядра.

## Честный статус

TV-экран запуска уже написан, но APK должен пройти автоматическую сборку. Полная кастомная библиотека, привязка графических профилей и фильтров к рендереру, а также проверка на физической RK3528-приставке ещё не завершены. Успешный CI build не заменяет проверку на самой приставке.

BIOS и игры не входят в приложение. Используйте собственные законно полученные файлы. Flycast — GPL-2.0; лицензионные уведомления upstream должны сохраняться.
