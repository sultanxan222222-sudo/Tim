# Tim — PS4 Torrent Client

## Цель
Развивать существующий репозиторий Tim как проект homebrew-приложения для PS4. Итоговая цель — устанавливаемый `.pkg`, который запускается на консоли с HEN.

## Текущий статус
- `index.html` — веб-прототип каталога; сам по себе не является приложением PS4 и не может выполнять полноценные торрент-загрузки.
- `catalog.json` — описание каталога, а не торрент-движок.
- Готового PS4 `.pkg` в репозитории пока нет.

## Архитектура целевого приложения
1. **PS4 UI:** интерфейс под DualShock 4, карточки, поиск, очередь, экран деталей.
2. **Torrent engine:** отдельный нативный компонент с поддержкой magnet URI, .torrent, DHT/PEX и проверки хешей, если это поддерживается выбранной библиотекой и окружением PS4.
3. **Download manager:** очередь, пауза/возобновление, скорость, получено/всего, состояние пиров и ошибки.
4. **Storage:** выбор доступного каталога назначения, проверка свободного места и обработка неполных загрузок.
5. **Build:** воспроизводимая сборка ELF и упаковка в PS4 PKG с использованием совместимого PS4 homebrew SDK/toolchain.
6. **Testing:** сначала сборка и запуск пустого homebrew-приложения, затем тест движка на легальном тестовом торренте, затем интеграция UI и очереди.

## Источник каталога
Единственный заданный пользователем источник каталога: https://pirategames.ru/ps4/

Страница каталога не является торрент-движком и не гарантирует наличие прямых magnet/.torrent ссылок. Не следует выдумывать URL раздач или отображать фиктивный прогресс.

## Критерии готовности
- Создан настоящий PS4 `.pkg`, а не HTML-архив.
- Пакет устанавливается и запускается на целевой PS4 с совместимым homebrew-окружением.
- Тестовая разрешённая раздача проходит от начала до конца; скорость и прогресс отражают фактические данные движка.
- Ошибки сети и нехватка места показываются пользователю.
- В каталоге не подставляются фиктивные ссылки или результаты.

## Ограничения текущей среды
Публикация файлов в GitHub сама по себе не создаёт PS4 PKG. Для сборки необходимы совместимые исходники/библиотека торрент-движка и PS4 toolchain; успешную сборку можно заявлять только после выполнения сборочного процесса и проверки артефакта.
